# 내 첫 번째 아이디어 (My First Idea)

화면 중앙에 '내 첫 번째 아이디어'라는 문구를 감각적인 다크 사파이어 글래스모피즘(Glassmorphism)과 반응형 인터랙션으로 표현한 웹 프로젝트입니다.

## ✨ 주요 기능
- **중앙 포커스 타이포그래피**: '내 첫 번째 아이디어' 문구에 생동감 넘치는 일렉트릭 블루 쉬머(Shimmer) 애니메이션 적용
- **3D 카드 틸트(Tilt)**: 마우스 커서의 움직임에 따라 카드가 입체적으로 부드럽게 반응
- **동적 캔버스 배경**: 은은하게 유영하는 파티클과 성간 연결선 효과
- **인터랙티브 영감 생성기**: 클릭 시 화려한 빛 파티클 버스트와 함께 새로운 영감의 문구 순환
- **아이디어 기록함**: 떠오른 아이디어를 브라우저 `localStorage`에 바로 기록하고 보관하는 미니 노트 기능
- **문구 클립보드 복사**: 클릭 한 번으로 문구 복사 및 토스트 알림

## 🛠️ 기술 스택
- **HTML5**: 시맨틱 웹 구조
- **CSS3**: 순수 Vanilla CSS, 커스텀 변수 기반 디자인 토큰, 글래스모피즘 및 키프레임 애니메이션
- **JavaScript (ES6+)**: 캔버스 렌더링, 3D 틸트 계산 및 로컬 스토리지 연동

## 🚀 실행 방법
`index.html` 파일을 브라우저(Chrome, Edge 등)에서 직접 열어 확인하실 수 있습니다.
